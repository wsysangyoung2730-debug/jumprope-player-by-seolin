# 개발 규칙

macOS가 기본 제품이다. iPadOS는 공통 기능을 터치와 가변 창에 맞게 제공한다.

- `main`: 출시 브랜치. 초기 커밋 외 개발 변경을 직접 넣지 않는다.
- `develop`: 통합 개발 브랜치.
- 범위별 이슈 작성 후 `태그/#이슈번호-작업하는파일` 브랜치를 만든다.
- 커밋: `[태그] 한글 명령조 작업 내용`, 제목 50자 이내.
- 태그: `init`, `feat`, `fix`, `docs`, `setting`, `add`, `refactor`, `chore`.
- PR 전 작업 브랜치에 최신 `develop`을 병합해 충돌과 검증 결과를 확인한다.
- PR의 대상은 `develop`. 확인된 작업을 병합하고 이슈 완료 기준을 갱신한다.
- 코드 구현, 빌드 검증, 실기기 검증을 구분해 기록한다.
