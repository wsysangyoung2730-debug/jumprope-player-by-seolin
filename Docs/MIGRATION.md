# 기존 데이터 가져오기

HTML 파일 자체에는 사용자가 편집한 순서표가 들어 있지 않습니다. 그 데이터를 작성하던 브라우저의 저장소에 있습니다.

1. 순서표를 사용하던 **같은 브라우저·같은 프로필·같은 원본 HTML 페이지**를 엽니다.
2. 브라우저 개발자 도구의 Console에서 `Scripts/export-browser-data.js` 내용을 실행합니다. `jrp:` 항목만 읽어 JSON을 다운로드하며 서버로 전송하지 않습니다.
3. Swift 앱의 설정 → 백업·브라우저 데이터 가져오기에서 JSON을 선택합니다.
4. 기존 음원·영상 파일 또는 폴더를 추가합니다. 파일 이름과 크기가 원본과 같으면 순서표와 싱크가 연결됩니다.
5. 일부 파일을 나중에 추가해도 미연결 순서표가 남아 있어 자동 연결됩니다. 이름이나 크기가 바뀐 파일은 기존 파일부터 가져온 후 파일 다시 연결 메뉴를 사용합니다.

브라우저의 폴더 접근 권한은 운영체제로 옮길 수 없으므로 폴더를 다시 선택해야 합니다. 즐겨찾기, 연결된 음원·영상 순서표, 표시 설정 및 매칭 가능한 정렬 순서를 가져옵니다.

# 앱 백업

설정 → 백업 내보내기로 JSON을 저장합니다. 앱 백업에는 순서표, 파일 연결 정보, 즐겨찾기, 정렬과 설정이 포함되며 원본 음원·영상 파일은 포함하지 않습니다. 가져오기는 사용자 확인 후 실행하며 현재 라이브러리의 복구 사본을 먼저 만듭니다. 다른 기기에서는 폴더·파일을 다시 연결해야 합니다. iCloud 자동 동기화는 제공하지 않습니다.
