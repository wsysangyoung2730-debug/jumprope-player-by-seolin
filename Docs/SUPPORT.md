# JUMPROPE PLAYER by SEOLIN 지원

Mac과 iPad에서 음원·영상과 동작 순서표를 연결하는 줄넘기 연습 앱입니다.

## 시작하기

1. 파일 추가 또는 폴더 추가로 연습 자료를 엽니다.
2. 순서표 편집에서 한 줄에 한 동작을 입력합니다.
3. 음악을 재생하며 '지금 싱크 찍기'를 누릅니다.
4. 구간 반복을 켜고 시작·끝 동작을 선택해 반복합니다.

앱 사이드바의 '사용 가이드'에서 자세한 안내를 볼 수 있습니다.

## 자주 묻는 질문

**파일이 재생되지 않아요.** MP3/M4A/WAV 또는 H.264·HEVC MP4/MOV를 권장합니다. 같은 확장자라도 코덱에 따라 재생되지 않을 수 있습니다.

**파일을 다시 연결하라고 나와요.** 파일을 이동했거나 외장 저장장치·파일 제공자의 접근 권한이 바뀌었을 수 있습니다. 목록의 다시 연결을 사용해 원본을 선택하세요.

**다른 기기로 옮기고 싶어요.** 설정에서 백업을 내보내고 새 기기에서 가져오세요. 음원·영상은 백업에 포함되지 않으므로 파일도 별도로 옮겨 다시 연결해야 합니다.

**기존 개발용 앱에서 App Store 앱으로 옮기고 싶어요.** 배포 앱의 보호된 저장 공간은 개발용 앱과 다를 수 있습니다. 기존 앱에서 먼저 JSON 백업을 내보낸 뒤 새 앱에서 가져오고 음원·영상 접근을 다시 허용하세요.

**파일을 제외하면 원본도 지워지나요?** 목록 제외는 원본 음원·영상 파일을 삭제하지 않습니다.

**iPad 화면을 나가면 음악이 멈춰요.** 이 앱은 화면을 보며 연습하는 용도로, iPad 백그라운드 재생은 지원하지 않습니다.
